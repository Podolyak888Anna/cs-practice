Рабочая папка — это папка на компьютере, где хранятся файлы проекта.
   Индекс — это промежуточная область, куда файлы добавляются перед сохранением.
   Коммит — это сохранение текущего состояния файлов в истории Git. 
Git — это локальная программа на компьютере для контроля версий.
GitHub - это сайт (облачный сервис) для хранения этих репозиториев.
Использованные команды:
git status - показывает состояние файлов. git diff — показывает разницу между рабочей папкой и индексом. git diff --staged - показывает разницу между индексом и последним коммитом.
Ветка (branch) в Git — это отдельная линия разработки. Она позволяет вносить изменения в код, не затрагивая основную ветку (main). Когда работа в ветке завершена и проверена, ее можно слить обратно в main. 
Это изменение сделано в отдельной ветке feature.
