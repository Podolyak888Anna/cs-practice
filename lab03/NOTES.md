Журнал вокршопа по Git
Разница команд:
- git diff показывает изменения в файлах (ЧТО мы изменили, но еще не сохранили).
- git show показывает полную информацию о конкретном коммите (кто, когда и что изменил).
- git log показывает историю коммитов.
- Команда log -S ищет коммиты, в которых менялось количество вхождений строки. А blame показывает, кто и в каком коммите последний раз менял каждую строчку в файле.
Команда git restore возвращает файл из индекса (если файл просто изменен), a git
restore --source=HEAD~2 возвращает
конкретную старую версию файла из указанного коммита. Мои правки, которые я не сохранила в коммит, просто исчезли бы.
Команда git revert безопасно отменяет изменения, создавая новый коммит с противоположными изменениями. Это отличается от git reset --hard, который просто стирает коммиты из истории. В опубликованной истории (на GitHub) revert безопаснее, потому что он не ломает историю для других людей, которые уже скачали проект.
Тег — это постоянное имя (метка) для конкретного коммита, по которому версию находят даже через полгода. Ветка — это подвижная линия разработки, которая меняется при новых коммитах.
